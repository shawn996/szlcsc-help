### 1.2 竞品弱点（我们的机会）

| 竞品 | 弱点 | 我们的差异化 |
|---|---|---|
| 官方领券中心 | 券按"活动类型"平铺（PLUS专区/会员日/运费券混杂），无元器件分类维度，无力度对比 | **按元器件分类聚合 + 每类标出最高满减**，工程师按"我要买什么"找券 |

| 内容站（与非网等） | 一次性活动报道，信息过时 | 数据每日自动刷新，时效性持续 |

## 四、后续建议（按优先级）

1. **提交收录**：push 后到百度站长平台 / Bing Webmaster 提交 `https://lcsc.fdemo.com/` 与 sitemap；
2. **程序化分类页**：`/cat/电阻.html` 等 400+ 静态分类落地页（由 main.py 构建时生成），承接「分类+优惠券」长尾矩阵——这是超越官方的最大的结构性机会；
3. **品牌聚合页**：同上，承接品牌词长尾；
4. **外链**：立创社区/电子论坛（立创开源广场、EEVblog 中文区、少数派等）分享"立创券大全"工具帖，工具型内容容易被自然引用；
5. **性能**：coupon_details.json ~4MB 首屏阻塞——考虑拆分/压缩（gzip 由 GitHub Pages 自动启用），LCP 可显著改善（Core Web Vitals 是排名信号）；
6. **监控**：接入百度统计/Search Console，观察「立创优惠券」相关 query 的展示与点击。
